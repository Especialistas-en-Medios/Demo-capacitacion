Pasos para completar el ejercicio
  1. Crea una nueva rama
    Ejecuta en tu terminal: git checkout -b feature/perfil-tu-nombre
  2. Crea tu tarjeta en la carpeta profiles/
    Copia el archivo profiles/template.html y renómbralo como profiles/tu-nombre.html. Edita tus datos: nombre, foto, puesto, bio y tecnologías. (Se cargará automáticamente).
  3. Haz commit y push
    git add .
    git commit -m "feat: agrega tarjeta de presentacion de Tu Nombre"
    git push origin feature/perfil-tu-nombre
  4. Abre un Pull Request
    Entra a GitHub y abre tu Pull Request hacia la rama principal (main).
